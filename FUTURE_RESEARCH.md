# Future research roadmap

This is a descriptive portfolio study, not a causal estimate. To make the claims stronger:

1. **Audit the 512 GB console filter:** hand-label a reproducible random sample (including borderline accessories, bundles and titles reporting "500 GB"). Publish a confusion matrix and a corrected summary. Keep any seller-identifying material private.
2. **Track a comparison product** over the same calendar dates with the same source and sampling rules (e.g., a used console not able to run GTA VI). A comparison is only meaningful when other price shocks and product trends are considered.
3. **Investigate the May–July eBay collection gap** only if budget and license terms permit; preserve missingness if it cannot be resolved.
4. **Observe the post-release period**, after 19 Nov, using consistent selection rules; do not add incomplete days as if final.
5. **Check 2025 seasonality** and, if available, current new-console retail prices and promotional discounts.
6. **Sensitivity analyses:** rerun medians with alternative product rules, remove implausible accessories and bundles, use transaction-weighted aggregate comparisons where appropriate, and report sample sizes and uncertainty.
7. **Avoid overclaiming causal inference.** The 1 Aug Microsoft retail price increase coincides with the onset of the continuously observed August–November eBay segment; a simple pre/post GTA VI comparison alone cannot attribute change to the game.
